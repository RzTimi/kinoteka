# Кінотека

Android-застосунок для каталогу фільмів, серіалів, дорам, аніме, мультфільмів і документального кіно.
Дані беруться з [TMDB](https://www.themoviedb.org/) українською мовою, а ваші оцінки, статуси й нотатки зберігаються на телефоні.

## Можливості
- Розділи: Фільми · Серіали · Дорами · Аніме · Мультфільми · Документальне
- Добірки на головній: популярне, зараз у кіно / зараз виходять, новинки, найкращі
- Жанри з сортуванням, фільтр дорам за країною
- Пошук по всіх розділах
- Картка фільму: опис, актори, сезони, «Де подивитись в Україні»
- Трейлери прямо в застосунку (вбудований плеєр YouTube)
- Мої оцінки: 1–10 зірок, статуси (Хочу / Дивлюсь / Переглянуто / Кинув), нотатки, статистика

## Збірка
1. Отримайте безкоштовний ключ на [themoviedb.org](https://www.themoviedb.org/settings/api).
2. У корені проєкту створіть або відкрийте `local.properties` і додайте:
   ```
   TMDB_API_KEY=ваш_ключ
   ```
   Підходить як короткий «API Key», так і довгий «API Read Access Token». Файл не потрапляє в git.
3. Відкрийте проєкт в Android Studio і натисніть ▶ Run.

Стек: Kotlin, Jetpack Compose (Material 3), Retrofit + kotlinx.serialization, Coil, Navigation Compose, android-youtube-player.
