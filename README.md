# Кінотека

Android-застосунок для каталогу фільмів, серіалів, дорам, аніме, мультфільмів і документального кіно.
Дані беруться з [TMDB](https://www.themoviedb.org/) українською мовою, а ваші оцінки, статуси й нотатки зберігаються на телефоні та (за бажанням) на вашому Google Диску.

## Можливості
- Розділи: Фільми · Серіали · Дорами · Аніме · Мультфільми · Документальне
- Додаткові розділи (вмикаються в налаштуваннях): Турецькі серіали, Українське, Індійське кіно, Корейське кіно, Реаліті-шоу, Класика, Короткометражки
- Добірки на головній: популярне, зараз у кіно / зараз виходять, новинки, найкращі
- Жанри з сортуванням, фільтр дорам за країною
- Пошук по всіх розділах
- Картка фільму: опис, актори, сезони, «Де подивитись в Україні»
- Трейлери прямо в застосунку (вбудований плеєр YouTube)
- Моя оцінка у вигляді змійки 🐍 (1–10), статуси (Хочу подивитись / Дивлюсь / Переглядаю / Переглянуто / Відкладено / Кинув), мітка ❤ Улюблене, нотатки, статистика
- Свій постер: з галереї (з обрізкою 2:3) або інший постер TMDB
- Синхронізація з Google Диском: папка «Кінотека» (data.json + posters/), доступ лише до своєї папки
- Налаштування: розмір інтерфейсу, вигляд кнопок розділів (таблетки / з іконками / вкладки / плитки), вибір і порядок розділів

## Збірка
1. Отримайте безкоштовний ключ на [themoviedb.org](https://www.themoviedb.org/settings/api).
2. У корені проєкту створіть або відкрийте `local.properties` і додайте:
   ```
   TMDB_API_KEY=ваш_ключ
   ```
   Підходить як короткий «API Key», так і довгий «API Read Access Token». Файл не потрапляє в git.
3. Відкрийте проєкт в Android Studio і натисніть ▶ Run.
4. Для входу через Google потрібен проєкт у Google Cloud: увімкнений Google Drive API, екран згоди з областю `drive.file` і OAuth-клієнт Android (пакет `com.kinoteka.app` + SHA-1 вашого ключа підпису).

Релізна збірка підписується ключем із `keystore.properties` (не потрапляє в git).

Стек: Kotlin, Jetpack Compose (Material 3), Retrofit + kotlinx.serialization, Coil, Navigation Compose, android-youtube-player, Google Identity (play-services-auth), Google Drive REST API.
